# Replicator 2 configuration 

Features:
- Single extruder
- Type K thermocouple
- No heat bed
- Print Area 250mm x 150mm 
- Mightyboard interface 
- RGB LED

Board: Mightyboard 2, also known as Mightyboard revision G/H
- micro: Atmega1280
- ADS1118 and thermocouples
- Digitpots

- Flashing: USB or ISP
